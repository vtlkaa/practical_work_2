# Практическая работа № 2

## Этап 1. Конфигурация CLI-приложения

Приложение на Python загружает пользовательские настройки из XML-файла и выводит их в формате «ключ — значение».

### Настраиваемые параметры

- `package_name` - имя анализируемого пакета.
- `repository` - URL репозитория или путь к файлу тестового репозитория.
- `test_mode` - режим работы с тестовым репозиторием.

### Запуск

Из корневой папки проекта выполните:

```bash
python src/main.py
```

### Конфигурация

Настройки находятся в файле `config/config.xml`.

Приложение обрабатывает отсутствие конфигурационного файла, некорректный XML и отсутствие или пустое значение каждого из трёх параметров.

## Этап 2. Сбор данных о зависимостях пакета

Приложение получает сведения о прямых зависимостях выбранного пакета Ubuntu из метаданных репозитория, используя URL-адрес репозитория.

Принцип работы

Загрузить метаданные репозитория по указанному URL.

Распаковать загруженный файл Packages.gz.

Найти запись пакета по значению параметра package_name.

Извлечь поле Depends, содержащее информацию о прямых зависимостях пакета.

Вывести найденные зависимости на экран.

Ограничения

Используется формат метаданных пакетов Ubuntu (APT).

Для получения информации о зависимостях не используются менеджеры пакетов и сторонние библиотеки.

Загрузка данных, распаковка и обработка метаданных выполняются средствами стандартной библиотеки Python.

Результат

При успешном выполнении приложение выводит прямые зависимости выбранного пакета. Если запись пакета не найдена, выводится соответствующее сообщение.

## Этап 3. Построение графа зависимостей

### Цель работы

Реализовать построение графа зависимостей пакетов с использованием рекурсивного алгоритма поиска в глубину (DFS), а также обнаружение циклических зависимостей.

### Реализованные возможности

- Построение графа прямых и транзитивных зависимостей пакета.
- Рекурсивный обход зависимостей с помощью DFS.
- Отслеживание посещённых пакетов для исключения повторной обработки.
- Обнаружение циклических зависимостей.
- Поддержка тестового репозитория с искусственным графом зависимостей.
- Проверка корректности тестовых данных: формата строк, уникальности пакетов и наличия всех указанных зависимостей.
- Обработка ошибок при чтении конфигурации и репозитория.

### Тестирование

Для проверки алгоритма используется искусственный репозиторий `tests/data/repository.txt`, позволяющий проверить различные варианты графа:

- Граф с несколькими ветвями и общей зависимостью.
- Пакет без зависимостей.
- Последовательная цепочка зависимостей.
- Несколько пакетов с общими зависимостями.
- Циклы из двух и более пакетов.

Режим тестирования выбирается с помощью конфигурационного файла `config_test.xml`.

### Результат

Реализован алгоритм построения графа зависимостей с помощью рекурсивного DFS. Программа обрабатывает ветвления и общие зависимости, а также обнаруживает циклические зависимости, не допуская бесконечного рекурсивного обхода.

## Этап 4. Дополнительные операции

**Цель:** реализовать поиск обратных зависимостей заданного пакета в тестовом репозитории.

### Реализация

Добавлена функция `find_reverse_dependencies(package_name, graph)`, которая находит пакеты, зависящие от указанного пакета.

Для поиска используется алгоритм обхода графа в глубину (DFS), применявшийся на предыдущем этапе.

Алгоритм работы:
1. Строится обратный граф зависимостей, в котором для каждого пакета хранятся пакеты, зависящие от него.
2. Выполняется обход графа в глубину, начиная с заданного пакета.
3. Посещённые пакеты сохраняются в множестве `visited`, чтобы избежать повторного посещения и зацикливания.
4. Все найденные обратные зависимости выводятся на экран.
5. Если обратных зависимостей нет, выводится соответствующее сообщение.

Поиск учитывает как прямые, так и транзитивные обратные зависимости.

### Запуск программы

Для проверки используется тестовая конфигурация `config/config_test.xml`, содержащая имя пакета и путь к тестовому репозиторию `tests/data/repository.txt`.

Запуск из корневой директории проекта:

```powershell
python src/main.py
```

### Проверка функциональности

Для демонстрации работы этапа использованы различные пакеты тестового репозитория.


### Результат этапа

Реализован поиск прямых и транзитивных обратных зависимостей с использованием DFS. Проверена работа алгоритма на нескольких случаях тестового репозитория, включая отсутствие обратных зависимостей и циклическую зависимость.
