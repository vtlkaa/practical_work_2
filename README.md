# Практическая работа № 2

## Этап 1. Конфигурация CLI-приложения

Приложение на Python загружает пользовательские настройки из XML-файла и выводит их в формате «ключ — значение».

### Настраиваемые параметры

- `package_name` - имя анализируемого пакета.
- `repository` - URL репозитория или путь к файлу тестового репозитория.
- `test_mode` - режим работы с тестовым репозиторием.

### Запуск

Из корневой папки проекта выполните:

```bash
python src/main.py
```

### Конфигурация

Настройки находятся в файле `config/config.xml`.

Приложение обрабатывает отсутствие конфигурационного файла, некорректный XML и отсутствие или пустое значение каждого из трёх параметров.

## Этап 2. Сбор данных о зависимостях пакета

Приложение получает сведения о прямых зависимостях выбранного пакета Ubuntu из метаданных репозитория, используя URL-адрес репозитория.

Принцип работы

Загрузить метаданные репозитория по указанному URL.

Распаковать загруженный файл Packages.gz.

Найти запись пакета по значению параметра package_name.

Извлечь поле Depends, содержащее информацию о прямых зависимостях пакета.

Вывести найденные зависимости на экран.

Ограничения

Используется формат метаданных пакетов Ubuntu (APT).

Для получения информации о зависимостях не используются менеджеры пакетов и сторонние библиотеки.

Загрузка данных, распаковка и обработка метаданных выполняются средствами стандартной библиотеки Python.

Результат

При успешном выполнении приложение выводит прямые зависимости выбранного пакета. Если запись пакета не найдена, выводится соответствующее сообщение.
